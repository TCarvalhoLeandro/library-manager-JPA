
<h1 align="center">Sistema de Gestão de Biblioteca 📚</h1>

Sistema web desenvolvido para gerir o catálogo de livros e os empréstimos de uma biblioteca, 
aplicando conceitos avançados de Programação Orientada a Objetos e persistência de dados.

## 🛠️ Tecnologias Utilizadas

Neste projeto, foram aplicadas as seguintes tecnologias e ferramentas:

Linguagem: Java

Framework principal: Spring Boot

Acesso a Dados: JPA e Hibernate

Interface: Thymeleaf

Base de Dados: MySQL

Ferramentas: Git, Maven e Spring Tool Suite (STS) / Eclipse

Ambiente: Desenvolvido e testado em ambiente Linux (Ubuntu)

## ⚙️ Funcionalidades
[x] Registo e gestão de entidades (ex: Livros, Autores, Leitores)

[x] Operações de CRUD (Criar, Ler, Atualizar, Apagar) com a base de dados

[x] Tratamento de exceções e validação de dados

Adicionando outras funcionalidades.

## ☁️ Acesso ao Projeto 
A aplicação está hospedada na nuvem e pode ser acessada diretamente pelo link abaixo:

🔗 [Acessar a Aplicação Online](https://library-manager-jpa.onrender.com)

Backend: Hospedado no Render

Banco de Dados: Serveless database gerenciado pelo Neon

⚠️ Aviso Importante sobre o primeiro acesso: > Como o backend está hospedado na camada 
gratuita (Free Tier) do Render, a aplicação entra em modo de suspensão (sleep) após um 
período de inatividade para economizar recursos.

O que isso significa? Ao clicar no link pela primeira vez, o servidor pode levar cerca 
de 30 a 50 segundos para "acordar" e carregar a página ou responder à primeira requisição 
da API. Por favor, aguarde alguns segundos. Após esse carregamento inicial, a navegação e 
o uso do sistema ocorrerão em velocidade normal!
